Narrativa central

Estrutura do workshop — 90 a 120 min
0–15 minBloco 1Contexto: o que é e o que não é IA
Diferenciar uso informal (ChatGPT pessoal) do Claude corporativo. Posicionar IA como amplificação, não substituição. Ponto-chave: "Vocês já usam isso — agora com estratégia."
15–40 minBloco 2Demo ao vivo — Claude gratuito
Casos do dia a dia da área visitada. Mostrar Claude.ai, mencionar Claude Code para perfis técnicos. Gancho: "A empresa libera licença paga para quem estiver efetivamente usando o gratuito."
40–65 minBloco 3Brainstorm estruturado
3 perguntas gatilho: (1) Qual tarefa repetitiva mais te toma tempo? (2) Onde existe mais retrabalho? (3) Se pudesse automatizar uma coisa, qual seria? Cada ideia cadastrada no banco em tempo real.
65–85 minBloco 4Votação ao vivo
Participantes votam nas ideias mais impactantes. Rafael faz triagem: Claude (ferramentas, calculadoras, apps) vs Copilot Studio (agentes Q&A). Resultado: 1-2 ideias eleitas.
85–105 minBloco 5Hands-on — primeiro prompt real
Todos abrem o Claude.ai e testam com uma tarefa real. Ninguém sai sem ter usado. Perfis técnicos recebem orientação sobre Claude Code.
105–120 minEncerramentoCombinados e próximos passos
Definir responsável por cada ideia eleita. Combinar check-in de 30 dias. Reforçar o banco de ideias para cadastros posteriores.

Stack aprovado — Positivo TecnologIA
PROTOTIPAGEM
Claude Team (claude.ai) — ponto de partida obrigatório para qualquer nova iniciativa. Prototipe aqui antes de evoluir para produção.
LLM PRIMÁRIO
claude-sonnet-4.6 — tarefas padrão / custo-benefício.
claude-opus-4.6 — tarefas cognitivas complexas.
LiteLLM Router → GPT-4o (Azure) — fallback automático.
AGENTES & FLUXOS
LangGraph — agente único com estado/memória complexa.
CrewAI — múltiplos agentes colaborativos com papéis definidos.
n8n — orquestração de fluxos, webhooks, ETL, triggers.
DADOS & MEMÓRIA
Qdrant — RAG alta frequência / missão crítica.
pgvector — RAG complementar (integrado ao PostgreSQL).
Redis — cache semântico (reduz 35-40% chamadas LLM).
CI/CD & DEPLOY
GitLab → pipeline automático (test → scan → eval → build → deploy).
ArgoCD → KUBIA — deploy GitOps no cluster on-premise.
GMUD via Zeev + GLPI — aprovação obrigatória para produção.
OBSERVABILIDADE
Langfuse — FinOps de tokens por projeto/agente/modelo.
OpenTelemetry — tracing obrigatório em todos os agentes.
Prometheus + Grafana — métricas operacionais.
Loki — logs estruturados.
